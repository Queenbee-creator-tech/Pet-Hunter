# Pet Hunter

Mobile-first creature discovery, raising, and eventual combat game. First release: touch-friendly text adventure, with a separate reusable game engine.

## Status
Early worldbuilding. Biomes, names, species, balancing, and gameplay rules are provisional.

## Starting concept
- Four planned biomes: forest, ice, desert, volcanic. Names TBD.
- Per biome: 6 common (white), 12 rare (blue), 4 epic (purple), 2 legendary (gold) species — 24 per biome, 96 total planned.
- Separate species rarity from mutation rarity.
- Default growth: baby → adolescent → young adult → adult.
- Explore, discover, acquire offspring/eggs or tame when species-appropriate, raise, train, and eventually battle other players.
